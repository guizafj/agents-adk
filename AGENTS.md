# AGENTS.md

Hybrid Google ADK (locked at 2.2.0) + local Ollama. Multi-agent repo: each top-level dir is a standalone ADK agent exporting `root_agent` from `agent.py`. Docs (README.md, tutor/*.md) reference a removed `chat_agent/` — they are stale; trust the agent dirs.

## Agents
- `Cybersegurity_tutor/` — cybersecurity tutor; also owns the shared `database/` package (`AgentPersistence` in `Cybersegurity_tutor/database/agent_wrapper.py`). This is the agent Docker serves (image `tutor:latest`).
- `Analist_cv/` — does `from Cybersegurity_tutor.database import AgentPersistence` (cross-package import). Must be run from repo root; cannot be served standalone.
- `pokedex_agent/` — minimal tool-using agent.

## Run
- Ollama runs **natively on the host** at `localhost:11434`, never containerized. Pull before running: `ollama pull qwen3.6:35b` (compose default; agents may override with `OLLAMA_MODEL`).
- Web UI (serves all agents): `uv run adk web .` → http://localhost:8000
- Single agent CLI: `uv run adk run Cybersegurity_tutor`
- Docker: `docker compose up --build -d`; `docker compose logs -f adk`; `docker compose restart adk`. `docker compose down -v` **wipes session history**. `network_mode: host` in compose is required to reach host Ollama.

## Env config
- Each agent dir has its own `.env` (gitignored), loaded via `load_dotenv()` in `agent.py`; `Cybersegurity_tutor/.env.example` is the template.
- Key vars: `OLLAMA_API_BASE` (falls back to `OLLAMA_BASE_URL`), `OLLAMA_MODEL` (`ollama_chat/<model>`), `OLLAMA_NUM_CTX=8192` (qwen defaults to 2048 → truncated context), `LITELLM_REQUEST_TIMEOUT=300` (thinking tokens make qwen slow), `LITELLM_CONNECT_TIMEOUT=30`, `PERSISTENCE_DB_PATH`.

## Persistence
- Session history lives in SQLite (`DatabaseSessionService` in Cybersegurity_tutor, `AgentPersistence` in Analist_cv), default `/app/data/persistence/sessions.db`. In Docker it's the named volume `tutor_persistence`; `.env`/`data/persistence/`/`*.db` are gitignored.

## Dev / quality
- Package manager: `uv` (Python 3.11). Use `uv add <pkg>` / `uv sync`. `requirements.txt` is autogenerated by `uv export` — don't hand-edit.
- pre-commit: run `pre-commit run --all-files` (the `Makefile` targets `venv`/`install`/`precommit` are broken — indented with spaces, not tabs).
- Hooks: ruff (lint + format, `--fix`), pydocstyle (Google convention on public functions), detect-secrets (baseline `.secrets.baseline` — rescan if adding secrets), bandit, pip-audit. No ruff/bandit config exists in pyproject.toml; defaults apply.
- No test suite configured.
